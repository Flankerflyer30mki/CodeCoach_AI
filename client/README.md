# CodeCoach AI: client

React + Vite + Tailwind frontend. See the root README for what the product does.

```bash
npm install
npm run dev      # http://localhost:5173, calls http://localhost:5000 by default
npm run lint
npm run build
```

`VITE_API_BASE_URL` sets the backend address for production builds (see `.env.example`).
It is public, so never put secrets in it.
